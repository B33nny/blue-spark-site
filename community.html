Automate this

Mask personal data before it reaches a public cloud chatbot.

Raw Document → Local Regex / Tokenizer → Masked Cloud LLM → Local Value Restore

The problem
Staff copy customer emails, MyKad numbers, passport records or bank details straight into public chatbots to draft letters or reconcile invoices — a PDPA liability.
The build
A local script or bookmarklet swaps personal details for placeholder tokens, sends the masked text to the cloud model, then restores the real values locally.
Keep a human for
Confirming no contextual clues leak identity, and approving the final correspondence.

Business opportunity

A sovereign AI tender-readiness audit for Malaysian vendors.

With the Sovereign AI Cloud confirmed, tender evaluation criteria will start disqualifying contractors that rely on foreign-hosted, multi-tenant AI APIs for public records. Offer a flat-fee audit that reviews a vendor's architecture, flags unshielded overseas dependencies, and routes them to local or sovereign cloud models.

Test it cheaply: review tender specs on MyProcurement or call three local vendors.
